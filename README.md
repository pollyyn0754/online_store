# Учебный проект

## Описание:

Учебный проект - это разработка бэкенд-сервиса на Python,
который представляет собой ядро для интернет-магазина.

## Установка:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/pollyyn0754/online_store
```

2. Установите зависимости:
```bash
pip install poetry
```
```bash
poetry install
```

## Основные компоненты:

Созданы абстрактные классы BaseProduct и BaseEntity, класс-миксин PrintMixin, 
а также классы Product (с дочерними Smartphone и LawnGrass), Category, Order и ProductIterator. 

Для класса Product определены следующие свойства:
+ название (name),
+ описание (description), 
+ цена (price),
+ количество в наличии (quantity).

Дополнительные свойства классов-наследников от исходного класса Product:
+ «Смартфон» (Smartphone):
  + производительность (efficiency),
  + модель (model),
  + объем встроенной памяти (memory),
  + цвет (color).
+ «Трава газонная» (LawnGrass):
  + страна-производитель (country),
  + срок прорастания (germination_period),
  + цвет (color).

Для класса Category определены следующие свойства:
+ название (name),
+ описание (description),
+ список товаров категории (products).

Для класса Order определены следующие свойства:
+ экземпляр класса Product (ordered_product),
+ рассчитанная сумма (final_price).

Bспомогательный класс ProductIterator позволяет перебирать товары одной категории и 
возвращает очередной товар категории.

Миксин-класс PrintMixin при создании объекта выводит в консоль информацию о том, от какого класса и 
с какими параметрами был создан объект.

Реализованы функции:
+ подгрузка данных по категориям и товарам из файла JSON;
+ защита данных (настройка доступа, фильтрация некорректного ввода, проверка на соответствие правилам);
+ основные бизнес-процессы (инвентаризация по категориям, стоимостная оценка остатков, Количественный учет);

### Тестирование
В пакете `tests` написаны тесты ко всем функциям проекта. Модули тестируются в отдельных тестовых файлах.

Тесты запускаются командой:
```bash
pytest
```
Генерация консольного отчета:
```bash
pytest --cov
```
Отчет о тестировании хранится в пакете `htmlcov`. Покрытие функционального кода тестами — 100%.
